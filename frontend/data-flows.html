Examples that were stuck: discoverlosangeles.com/events (378 events extracted), concertfix.com/vancouver (92), eventbrite.fr/paris (56), edinburghtourist.co.uk (67).
Bottleneck (now): Cadence-A cap is 50 sources / 24h. 74 trial sources never run yet — catchup ~2 days at current settings. Brave discovery + Gemini extraction are not the constraints; the per-fire cap and 18h re-run cooldown are.
